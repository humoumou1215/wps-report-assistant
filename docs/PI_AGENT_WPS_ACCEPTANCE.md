# Pi Agent Host：用户 WPS 实操验收

这些步骤需要真实 WPS。自动测试不能证明 COM/JSAPI、字体、表格形状以及不同 WPS 版本的行为。请使用测试文档及备份数据目录；Go Core 保留到 Windows、macOS 均通过为止。

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 安装与启动 | 安装后重新登录系统，同时打开 ET 和 WPP | 无需安装 Node/npm/Pi；两个面板连到同一 127.0.0.1:17891 Agent Host |
| 普通区域 | 读取含“部门/员工类型/本年预算”的区域 | 表头及预览一致，读取本身不产生 AI Session |
| 整列 | 选择 A:G，已有数据到第 800 行；生成后添加第 801 行再重算 | 只读取 UsedRange 交集，新增行自动进入 Source；无百万行读取卡死 |
| 整行、整表 | 选择已用区域中的整行，再选择整表 | 交集正确；超过 5000 数据行/200 列明确拒绝 |
| 创建变量 | 要求“正式员工，按本年预算降序，前10名” | 显示阶段进度；结果源于完整数据执行；保存前项目变量数量不变 |
| 取消 | 预览后取消任务 | 不新增 Source/Variable，不提交对应记忆 |
| 自动修复 | 使用本地脚本化模型测试语法错误后修复，或记录实际失败案例 | 显示失败/修复状态；错误候选不能直接保存 |
| 会话恢复 | 保存变量，关闭 WPS 与 Agent Host，重启后要求“改成升序” | 复用原 sessionId；仍记得正式员工和本年预算要求 |
| 语义记忆 | 明确纠正“不是状态字段，是员工类型”，确认后重启 | memory.md 保留纠正；不把旧行数/金额当实时事实 |
| 双绑定 | 同一变量绑定 PPT A（万元）和 B（元），调整 B | 共用变量 Session，但 B 不继承 A 单位；目标有稳定 ID |
| 确定性重算 | 只修改原 Source 数据，点击重算 | 无 Agent Turn；结果更新；PPT 不自动写入 |
| 源结构变化 | 把“本年预算”改为“年度预算”后重算 | 失败时保留旧 Source/Variable；让 AI 修复产生预览，确认才提交 |
| 目标变化 | 生成绑定预览后手动修改目标文字、字体或表格，再 Apply | 拒绝旧预览；提示重新生成；不覆盖手动修改 |
| 版本冲突 | 预览后在另一面板更新变量，再确认 | 提示 stale revision；不提交旧候选 |
| Apply / Undo | 确认文本和表格输出，再撤销 | Before/After 与绑定日志正确；撤销恢复内容、格式与规则 |
| 中断恢复 | 在已准备的修改中关闭宿主/服务，再重新打开 | 未完成条目可识别；恢复前不重复写入；按快照证据处理 |
| 生成中断 | Agent 生成时退出服务，重新启动打开面板 | 列出未完成生成任务；继续复用 Session，可取消或重新生成 |
| 风险确认 | 语义复核连续失败 | 预览明确列出问题；未勾选接受风险不能保存/应用 |
| 密钥 | 保存 API Key，重新打开设置，导出默认诊断 | 输入框不回填密钥；接口只回 configured 状态；诊断无密钥和完整表格 |
| 并发 | ET/WPP 同时请求同一变量和不同变量 | 同一变量忙碌被明确拒绝；不同变量最多两个并行 |
| 升级/卸载 | 带旧 state.json 升级，检查历史，再卸载 | 旧数据、重算、绑定与变更记录可用；卸载保留用户数据 |

记录每项的 OS、WPS 完整版本、通过/失败、复现步骤及诊断文件。包含业务数据的诊断只在主动勾选后导出。请勿在反馈中附 API Key。
