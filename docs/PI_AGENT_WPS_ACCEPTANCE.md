# 真实 WPS 人工验收

模拟宿主测试覆盖业务逻辑，但不能证明真实 WPS 的 COM/JSAPI、文字格式、演示对象布局或安装注册行为。使用可丢弃的测试文档；不要在验收时指向真实项目数据目录。

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 安装与启动 | 安装后重开 WPS，在表格、文字、演示分别打开助手 | 三种宿主进入同一工作区；本地服务可连接；无需另装 Node/npm |
| 项目与引用 | 创建项目，加入多个文件；用 `@` 引用文件和变量 | 所属关系正确；跨项目引用被拒绝；切换会话后草稿和消息正常 |
| 表格选区 | 引用普通范围、整行/整列和整表，包含空白边缘与新增数据行 | 读取范围正确；整行/列裁剪到 UsedRange；过大选区明确拒绝 |
| 变量计算 | 从选区提取变量，再通过自然语言筛选、排序、汇总并保存 | 显示真实计算结果；保存后 lineage、解释版本与来源正确；源数据刷新可重算下游变量 |
| 文本写入 | 选择文字或段落，要求插入/替换内容并运行 | 只改指定目标；After 快照与实际内容相符；Undo 恢复原文和格式 |
| 表格写入 | 选择 WPS 表格区域及 Writer/PPT 表格，生成并应用输出 | 越界、合并单元格或不受支持的结构在写入前拒绝；支持的格式和布局正确 |
| 演示文稿 | 更新指定幻灯片文本框或表格，并检查字体、颜色、对齐和尺寸 | 目标定位稳定；程序校验与 AI 语义验证均通过；视觉结果符合要求 |
| 撤销与冲突 | Render 后手动修改目标，再尝试 Undo；另对未改目标执行 Undo | 已手改目标时拒绝覆盖；未改目标恢复到 Before，历史中新增 Undo 记录 |
| 中断恢复 | 在写入中关闭 WPS/助手，再重开并连接原文件 | 未完成记录被识别；不会盲目重放；确认恢复后新增 Recovery 记录 |
| 审慎模式 | 设置为“每次修改前确认”，生成文档修改任务 | 确认前文档不变；确认后重新检查版本与目标，再执行一次 Render |
| 密钥与设置 | 保存密钥后重开设置并读取 API | 输入框不回填密钥，API 不返回密钥明文；修改自动化与时间线选项可持久保存 |
| 多宿主 | 同时打开 ET/WPP/WPS 面板并分别读取、写入测试文件 | 面板不会互相串文档；同文档并发写入受到串行保护 |

记录操作系统、WPS 完整版本、通过/失败和复现步骤。不要在反馈或诊断中附带 API Key 或未经脱敏的业务数据。
