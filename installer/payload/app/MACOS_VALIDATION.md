# macOS 安装与用户验收

更新日期：2026-09-20。按照用户要求，真实 WPS 操作验收留给用户执行。当前不把浏览器模拟结果视为 Mac WPS 已验收。

## 安装

1. 保存并完全退出 WPS。
2. Apple Silicon 使用 `dist/macos-arm64/安装.command`；Intel 使用 `dist/macos-amd64/安装.command`。安装程序与 command 文件要保持在同一目录。
3. 双击安装后重新打开 WPS，在“数据报告助手”选项卡点击“打开助手”。
4. 若入口未出现，请记录 WPS 版本和截图；不要通过关闭系统安全保护来强行加载。

开发者构建：`./build-macos.sh arm64` 或 `./build-macos.sh amd64`。安装器未进行 Apple 开发者签名和公证，分发到其他 Mac 时需遵循该机器正常的应用安装流程。

安装位置：

- 程序：`~/Library/Application Support/DataReportAssistant/app`
- 数据和历史：`~/Library/Application Support/DataReportAssistant/data`
- 登录启动：`~/Library/LaunchAgents/com.datareportassistant.core.plist`
- WPS 注册：`~/Library/Containers/com.kingsoft.wpsoffice.mac/Data/.kingsoft/wps/jsaddons/publish.xml`
- 服务检查：访问 `http://127.0.0.1:17891/`。只说明服务正常，不能证明 WPS 加载成功。

卸载运行同目录的 `卸载.command`：移除本插件注册、程序及登录启动项，保留项目数据和历史，也保留其他插件注册。

## 验收文件准备

使用可修改的测试文件。仓库 samples 提供表格和演示；另建一个包含文本及 2×2 表格的文字文稿，保存为 docx 或 odt。正式业务文件不用于首次验收。

## 必测流程

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 表格、文字、演示分别点击“打开助手” | 均出现“项目数据 / 输出 / 修改历史”侧栏，显示当前文件 |
| 2 | 在表格创建项目，选中含表头的数据，提取“金额合计”变量 | 先看到结果，保存后出现在项目数据列表 |
| 3 | 检查变量，修改要求为“金额平均值”并生成 | 显示新结果，可展开旧版本对比；返回修改不会保存 |
| 4 | 保存修改，再从变量历史恢复旧版本 | 数据与规则恢复；引用输出没有自动改动 |
| 5 | 在演示和文字中将当前文件加入同一项目，分别读取选中的文字 | 可创建变量，输入不受 Excel 限制 |
| 6 | 表格选空白单元格、演示选文本框、文字选一段占位文本，分别新建输出 | 生成方案时原文件不变；点击“应用到原稿”后修改原文件 |
| 7 | 打开修改历史，展开刚才的修改 | 可看位置、修改前后内容与规则 |
| 8 | 调整输出要求并应用，连续撤销 | 按从新到旧的顺序恢复内容、字体等格式与绑定规则 |
| 9 | 应用后刷新侧栏，再撤销 | 历史仍存在，撤销可用 |
| 10 | 应用后手工改动目标，再尝试撤销 | 提示后续修改冲突，不覆盖人工修改 |
| 11 | 对已存在且空间足够的表格对象写入表格变量，再撤销 | 原单元格内容和格式恢复；空间不足／合并区域应拒绝写入 |
| 12 | 打开另一种 WPS 支持格式，如 ods、odp 或 odt，重复读取和输出 | 根据宿主能力工作，不因后缀被限制 |
| 13 | 使用“从源文件重算”，再恢复变量历史 | 重算前结果可恢复；打开非源文件时提示打开正确文件 |

文字验收尤其检查：段落格式、混合字体、表格格式是否完整恢复，书签定位是否正确。如出现“缺少文字格式快照/恢复能力”，请反馈 WPS 版本和错误文本，该环境不能视为文字输出已通过。

## 已完成的本地证据

- Core 自动化覆盖 et / wps / wpp / 自定义宿主的 16 种输入输出组合，变量修改、旧版本恢复、名称与并发冲突。
- JavaScript 模拟宿主覆盖表格、文字、演示的快照／恢复，自定义能力注册、人工修改冲突、批量部分失败及中断恢复。
- 真实浏览器 + 独立 Core + 模拟 WPS，360 像素侧栏跑通：创建变量 30 → 修改为平均值 15 → 恢复 30 → 生成输出 → 写入 30.00 → 历史详情 → 撤销；页面重载后历史和撤销继续有效，页面无横向溢出。
- 本机安装注册和 LaunchAgent/Core 启动已实际执行；真实 WPS 已打开专用测试文件，但尚未验证插件入口及宿主读写。之后因锁屏无法继续，用户选择自行验收。
