# v0.6.0-rc1 用户验证清单

这份清单只用于实际验收，不是设计 SPEC。

## A. 安装与插件入口

1. 完全退出 WPS。
2. 双击 `DataReportAssistant-Setup-0.6.0-rc1.exe`，完成覆盖安装。
3. 重新打开 WPS 表格和 WPS 演示。
4. 两边顶部都应出现“数据报告助手”。
5. 打开插件设置，Core 状态应正常；若失败，查看：
   `%LOCALAPPDATA%\DataReportAssistant\data\core.log`

## B. 准备标准数据

1. 在插件设置中点击“准备标准测试项目”。
2. 应打开 `%USERPROFILE%\Documents\DataReportAssistant-标准测试项目`。
3. 用 WPS 打开：
   - `标准测试-本年预算.xlsx`
   - `标准测试-预算汇报.pptx`
4. 两个文件都应自动关联“标准测试项目”。

## C. Case A：验证 Preview/Apply + 金额单位

### Excel 侧

1. 在 `本年预算` 工作表选中 `A1:G15`。
2. 变量名：`正式预算合计`。
3. 描述：`只保留状态为正式的数据，计算预算金额合计。`
4. 点击“生成变量预览”。
5. 预期预览值：**66,600,000**，类型 Number。
6. 此时检查数据结果列表：**不应已经新增“正式预算合计”**。
7. 点击“确认创建变量”。
8. 此时变量才应出现在列表中。

### PPT 侧

1. 打开标准 PPT 第 2 页。
2. 选中原来显示 `12.30 亿元` 的金额文本框。
3. 选择变量 `正式预算合计`。
4. 描述：`按亿元显示，保留2位小数，后缀为“亿元”。`
5. 点击“生成绑定预览”。
6. 预期 RenderPlan 文本：**0.67亿元**。
7. 此时 PPT 文本框：**仍应保持原值，不应提前被改写**。
8. 点击“确认应用绑定”。
9. PPT 文本应变成 **0.67亿元**，绑定列表新增一条绑定。

## D. Case B：分组汇总 → PPT 表格

1. Excel 仍选中 `A1:G15`。
2. 变量名：`部门预算汇总`。
3. 描述：`只保留状态为正式的数据，按部门汇总预算金额和实际金额，按预算金额降序。`
4. 生成预览。
5. 预期：**10 行 × 3 列**（部门 / 预算金额 / 实际金额）。
6. 前 5 行预期：
   - 技术部：19,000,000 / 15,450,000
   - 销售部：11,900,000 / 11,360,000
   - 产品部：8,600,000 / 7,900,000
   - 市场部：6,100,000 / 5,830,000
   - 运营部：5,100,000 / 4,980,000
7. 确认创建变量。
8. PPT 第 3 页选择部门预算表格。
9. 描述：`第一列部门，第二列预算金额，第三列实际金额；金额按万元显示，不要改变列数，数据行随结果增减。`
10. 生成绑定预览并确认。
11. 预期表格：1 行表头 + 10 行数据；第一条数据为技术部 / 1,900 / 1,545（万元语义）。

## E. Case C：Top5

1. Excel 创建变量 `Top5预算部门`。
2. 描述：`只保留正式数据，按部门汇总预算金额，按预算金额降序取前5名。`
3. 预期顺序：技术部、销售部、产品部、市场部、运营部。
4. 绑定到 PPT 第 4 页表格。
5. 预期：1 行表头 + 5 行数据。

## F. 重点故障验收

请特别观察以下回归点：

- AI 引用了不存在的 Excel 字段时，不应保存错误变量；如果自动修复成功，预览中会显示多次生成尝试。
- 用户明确说“亿元/万元、保留 N 位”时，最终预览应服从用户描述，不应只改后缀而漏掉数值换算。
- 取消变量预览后，项目里不应出现 Source/Variable 残留。
- 取消绑定预览后，项目里不应出现 Binding，PPT 也不应变化。
- 如果绑定确认后 WPS 本地写入失败，插件应提示失败，并尽量删除刚保存的 Binding。

## G. 出问题时给我什么

复现失败后不要连续做很多其他操作：

1. 设置 → 开启“调试模式”。
2. 再复现一次问题。
3. 点击“导出诊断包”。
4. 把诊断 ZIP 发回来，并注明：`Case A/B/C + 哪一步 + 实际结果 + 预期结果`。

API Key 不会进入诊断包。
